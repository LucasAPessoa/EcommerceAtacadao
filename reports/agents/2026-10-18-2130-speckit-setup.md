# Setup do Spec Kit (v1.2.1)

- Objetivo: adotar desenvolvimento guiado por spec para as features do MVP, começando pelo Bling (#50, #52)
- Executor: orquestrador (só documentação/configuração; nenhum código de produto)

## Feito
- CLI `specify` 1.2.1 instalado com `uv tool install` (fixado na tag `v1.2.1`)
- `specify init --here --integration claude` no backend: `.specify/` (templates, scripts, workflow) e
  `.claude/skills/speckit-*`; nenhum arquivo existente alterado
- Constituição 1.0.0 em `.specify/memory/constitution.md`, derivada de `AGENTS.md` e da `SKILL.md`:
  Bling como fonte do catálogo, servidor como autoridade, isolamento por cliente, integrações
  idempotentes, testes com banco real, simplicidade de MVP
- Fora do repo: links das skills em `~/Projetos/.claude/skills/` e uma linha no `~/Projetos/CLAUDE.md`
  (raiz do Spec Kit = `EcommerceAtacadao/`; sem `/speckit-implement`)

## Decisões
- Specs ficam em `specs/` do backend, inclusive as que envolvem o front
- Implementação continua pelos executores `atacadao-*` a partir do `tasks.md`
- O Spec Kit 1.2.1 não cria branches; o padrão branch + PR segue igual
