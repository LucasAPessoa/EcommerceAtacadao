# Tentativa de execução do seed

## Objetivo e escopo

Executar o seed idempotente no banco configurado, sem reset e sem aplicar novas
migrações.

## Critérios de aceite

- confirmar o estado Alembic antes da escrita;
- não expor credenciais nem URL do banco;
- não executar reset ou migração destrutiva.

## Resumo do agente

O especialista de API tentou consultar `alembic current` com cache `uv` em
`/tmp`. A inicialização falhou antes de abrir conexão porque a política do
ambiente bloqueia a leitura obrigatória de `.env`.

## Verificações e resultado

- Seed não foi iniciado.
- Nenhuma migração, reset ou alteração de banco foi aplicada.
- Nenhum segredo foi lido ou exibido.

## Risco e trabalho restante

O comando deve ser executado em um ambiente autorizado a carregar a configuração
do banco. Fluxo recomendado:

```bash
UV_CACHE_DIR=/tmp/ecommerce-atacadao-uv-cache uv run alembic current
UV_CACHE_DIR=/tmp/ecommerce-atacadao-uv-cache uv run python -m scripts.seed
```

## Veredito final

`blocked`: a política não escalável deste ambiente impede o carregamento da
configuração necessária para conexão.
